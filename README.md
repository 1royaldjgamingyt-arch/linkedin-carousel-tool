# CarouselCraft — Free LinkedIn Carousel Generator 🚀

> **Live Website:** [https://linkedincarouseltool.in/](https://linkedincarouseltool.in/)

CarouselCraft is an ultra-fast, privacy-first, client-side web utility that converts standalone images (PNG, JPG, WebP) into crisp, swipeable LinkedIn carousel PDF documents.

Unlike heavy design platforms or paid subscription tools, CarouselCraft processes all files locally in your browser with zero server uploads, zero compression loss, and no mandatory login.

---

## 🌟 Key Features

- **100% Client-Side Processing:** High-resolution images are converted directly in your browser using modern Web APIs. No images ever touch an external server.
- **Zero Watermarks & No Sign-up:** Completely free forever without forced branding or login walls.
- **Live Mobile Preview:** Preview your carousel on a simulated LinkedIn mobile feed before publishing.
- **Drag-and-Drop Reordering:** Easily sort and arrange slide sequencing.
- **Optimized for 4:5 & 1:1 Ratios:** Perfect for mobile engagement (1080x1350px and 1080x1080px).
